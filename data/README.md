- xenonpy_normalized_v2.csv: Normalized elemental properties derived from XenonPy (66 elements × 58 properties).
- DRM_loop14.csv: Experimental DRM dataset comprising 697 catalysts accumulated through Loop 14, including nominal elemental loadings (mmol/g-support) and experimentally observed catalytic performance metrics.
- DRM_loop14_descriptor_pool.csv: Candidate descriptor pool generated from the Loop 14 catalyst compositions using XenonPy elemental properties.
- Test_example_C3.csv: Example candidate catalyst compositions generated under the C3 sampling condition (Ni loading fixed at 0.8 mmol/g-support).
- classification_descriptor_selection.csv: Results of GA-based descriptor selection for classification, including the best descriptor set and balanced accuracy for each generation.
- Prediction_result_train.csv: Classification and regression predictions for experimentally measured catalysts in the training dataset.
- Prediction_result_test_example.csv: Classification and regression predictions for example candidate catalysts.
- FPS_result_test_example.csv: Example catalyst recommendations obtained using FPS-PCA, including predicted performance and selection distances.
- tSNE_measured_samples.csv: Measured catalyst dataset containing loop-specific descriptor vectors, predicted H2 yields, experimental H2 yields, and the loop in which each catalyst entered the training dataset.
- tSNE_virtual_samples.csv: Virtual catalyst dataset containing loop-specific descriptor vectors and predicted H2 yields for t-SNE visualization.
- Catalyst_phylogenetic_tree_data.csv: Catalyst combination dataset containing elemental combinations, catalytic performance metrics, and loop identifiers for phylogenetic tree analysis.
- element_distance_matrix.csv: Pairwise elemental distance matrix used to calculate catalyst dissimilarities for phylogenetic tree construction.
