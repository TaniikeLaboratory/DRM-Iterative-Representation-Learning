# DRM-Iterative-Representation-Learning
Code, data, and reproducibility resources for active learning and iterative representation learning in DRM catalyst discovery.
- Generate_descriptor_pool.py: Generates catalyst descriptor pools from elemental compositions and normalized XenonPy properties through feature aggregation and nonlinear transformations. Supports both training and test datasets.
- Descriptor_selection_for_classification.py: Selects descriptor combinations using a genetic algorithm with a random forest classifier and leave-one-out cross-validation to classify catalysts by H2 yield (≥2% vs. <2%).
- Descriptor_selection_for_regression.py: Selects descriptor combinations using a genetic algorithm with Huber regression and leave-one-out cross-validation to predict H2 yield for catalysts with H2 yield ≥2%.
- Prediction.py: Performs classification and regression using descriptor sets manually specified based on GA selection results. By default, predictions are generated for the training samples; predictions for test candidates can be generated by switching the input and output file settings.
- FPS.py: Recommends candidate catalysts using farthest point sampling in PCA-reduced descriptor space. Prediction-based filtering can be enabled or disabled using the USE_FILTER flag.
- Generate_tSNE.py: Generates t-SNE maps of tested catalysts and untested candidates using loop-specific descriptor spaces and predicted H2 yields. The model and descriptor loops can be specified independently.
- Generate_phylogenetic_tree.py: Constructs a catalyst phylogenetic tree using pairwise elemental distances and the neighbor-joining method to visualize elemental-combination diversity of catalysts.
